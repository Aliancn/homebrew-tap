# Aliancn homebrew-tap

Homebrew tap for [Aliancn](https://github.com/Aliancn)'s tools.

## Install

```console
$ brew install Aliancn/tap/ml
```

## How it works

Formulae are updated automatically twice a day by
[maltmill](https://github.com/Songmu/maltmill) (see
`.github/workflows/update.yml`), which reads the assets and
`checksums.txt` of each tool's GitHub release.
